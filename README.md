# Timber

Cloud-first backend for named, persistent bots. Each bot owns one conversation, its instructions, memory and a reusable computer.

Native iOS is the intended product client. The initial milestone focuses on the Cloudflare backend and an authenticated developer console for end-to-end testing.

Implementation in progress: Cloudflare Workers, Durable Objects, R2, Workers AI, replaceable Pi runtime, and reusable desktop containers. No credentials belong in this repository.
